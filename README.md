## O que é a HYDERKS?

A **HYDERKS Optimizer** é uma aplicação para Windows criada para centralizar recursos de monitoramento, organização de perfis, controles de exibição e preparação de sessão. Ela foi pensada para jogadores, estudantes e pessoas que usam o computador em atividades mais exigentes e desejam comparar configurações com mais clareza.

Em vez de aplicar o mesmo ajuste para todos os programas, a HYDERKS permite trabalhar com perfis separados por jogo ou cenário. Assim, é possível manter opções diferentes de escala, captura, filtros, cursor e apresentação sem perder uma configuração conhecida que já funcionava bem.

> A HYDERKS não promete substituir hardware nem garantir o mesmo ganho de desempenho em todos os computadores. FPS, qualidade de imagem, estabilidade e latência variam conforme o jogo, GPU, CPU, RAM, drivers, resolução e configurações utilizadas.

## Recursos apresentados pela HYDERKS

| Recurso | Como ajuda no dia a dia |
| --- | --- |
| **Perfis por jogo** | Salve configurações separadas de escala, captura, exibição, cursor e filtros para cada cenário. |
| **Monitoramento em tempo real** | Acompanhe indicadores de CPU, memória RAM, GPU, VRAM, disco e rede para entender melhor o comportamento do PC. |
| **Overlay de FPS** | Exibe métricas de FPS e apresentação quando a telemetria compatível está disponível no sistema e no jogo. |
| **Scale Engine** | Organiza opções de escala espacial, como FSR/NIS, junto de controles de nitidez e imagem por perfil. |
| **Modo Automático** | Usa as informações de hardware disponíveis, como GPU, VRAM e resolução, para sugerir uma base de configuração. |
| **Filtros visuais** | Permite ajustar vibrância, gama, contraste e filtro noturno durante uma sessão compatível. |
| **Cursor e input lag** | Reúne controles de cursor, fila de frames e apresentação para testes individuais por jogo. |
| **Game Booster e Freezer de Apps** | Ajuda a organizar processos de segundo plano durante uma sessão, sempre exigindo atenção do usuário antes de aplicar mudanças. |

## Como usar com responsabilidade

Uma configuração confiável começa com uma comparação justa. Use sempre a mesma resolução, preset gráfico e área do jogo ao testar uma alteração. Mude uma opção por vez, anote o que aconteceu e mantenha um perfil anterior salvo para voltar caso o resultado não agrade.

O número de FPS é somente uma parte da análise. Estabilidade, tempo de quadro, uso de GPU, memória, qualidade de imagem, temperatura e resposta de entrada também podem influenciar a experiência. Nem todos os jogos e modos de tela fornecem as mesmas métricas de telemetria; quando uma informação não estiver disponível, ela não deve ser tratada como dado garantido.

## Compatibilidade

A versão atual da HYDERKS Optimizer é destinada a computadores de 64 bits com **Windows 10 versão 1903 ou posterior** e **Windows 11**. Alguns recursos dependem de compatibilidade com GPU, driver, jogo, modo de tela e fontes de telemetria. A instalação ser compatível não significa que todos os recursos terão comportamento idêntico em qualquer aplicativo.

Antes de instalar, mantenha o Windows e o driver da placa de vídeo atualizados pelos canais oficiais. Em notebooks, faça testes exigentes com o carregador conectado e confirme que o jogo já funciona normalmente antes de alterar uma configuração.
